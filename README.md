# ADG Lease downloads

Statische hosting voor campagnebestanden via GitHub Pages. Bestanden worden hier
geserveerd met `Content-Type: application/pdf` en zonder `Content-Disposition`,
zodat een telefoon de PDF direct in de browser opent in plaats van hem te downloaden.

Bron van de Mobiliteitswijzer: `PPC OS/clients/adg-groep/created/whitepaper/`.
De webversie wordt gebouwd met `build-mail-pdf.py` in diezelfde map.
